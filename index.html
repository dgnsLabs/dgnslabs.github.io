영상 업로드 규격 맞추기

업로드 화면에서 HD 720p MP4나 400MB 이하 파일을 요구할 때 사용하세요. 결과는 1280×720 MP4입니다. 원본 영상의 비율은 유지하고, 필요한 경우 가장자리에 검은 여백을 둡니다.

  1. 영상을 선택한 뒤 기본 자동 설정으로 변환을 시작합니다. 원본이 코덱과 용량 조건까지 충족하면 변환 없이 저장이 표시될 수 있습니다.
  2. 30MB 같은 별도 상한이 있다면 변환 설정 → 목표 용량 직접 입력에서 값을 지정합니다. 원본보다 커지는 것을 피하고 싶을 때는 원본 크기를 목표로를 선택합니다.
  3. 결과의 실제 크기와 목표 용량 충족 여부를 확인합니다. 업로드 규격을 통과해도 직접 정한 목표는 넘을 수 있습니다. 이 경우 설정 조정으로 돌아갈 수 있습니다.
  4. 미리보기에서 재생과 소리를 확인한 다음 결과 카드의 MP4 저장을 누릅니다.

변환이 오래 걸릴 때 첫 변환에는 처리 도구를 내려받는 시간이 들 수 있습니다. 긴 영상은 브라우저 화면을 열어두세요. 휴대폰에서 반복해서 실패하면 PC에서 같은 도구를 열어보세요.

사진의 위치와 개인정보 가리기

집에서 찍은 사진을 공개하기 전, 파일에 기록된 위치와 사진 속에 보이는 개인정보를 각각 확인하세요.

  1. 사진을 선택하고 주소표지, 차량 번호판, 얼굴처럼 이미지 자체에 찍힌 부분을 확대해 확인합니다.
  2. 필요한 부분에 모자이크나 블러를 칠하고 JPG 저장 또는 PNG 저장을 누릅니다. 사진이 다시 그려지면서 촬영 위치 등 EXIF가 제거됩니다.

EXIF 제거만으로는 이미지에 보이는 주소나 번호판이 가려지지 않습니다. 내보낸 파일을 다시 열어 가린 범위를 확인하세요.

첨부할 이미지 용량 줄이기

첨부 한도가 2MB인 양식에는 콘텐츠 규격을 선택합니다. 여러 장을 한 번에 넣고 결과 크기를 각각 확인할 수 있습니다.

  1. 사진을 선택한 뒤 2MB 프리셋을 적용합니다. PNG 원본은 투명도를 보존할 수 있도록 PNG로, 그 외에는 JPG로 처리됩니다.
  2. 글자가 많은 이미지라면 저장하기 전에 글자가 읽히는지 확인합니다. 양식의 제한이 더 낮을 때는 개별 설정에서 최대 폭이나 품질을 조정합니다.

양식에서 정확히 2,000,000바이트를 제한하는 경우 실제 파일 크기를 확인하세요. 이 프리셋은 2,097,152바이트를 기준으로 합니다. 보관용 원본은 따로 남겨두세요.

사진을 PDF로 묶거나 페이지를 이미지로 저장

신청서나 영수증 여러 장을 한 파일로 보내려면 이미지 → PDF를 선택합니다. 사진을 넣고 위에서부터 읽을 순서대로 재정렬한 뒤 페이지 크기를 고릅니다.

반대로 문서의 한 페이지를 메시지에 첨부하려면 PDF → 이미지로 열어 필요한 페이지를 개별 저장하세요. 전체 페이지가 필요할 때는 ZIP으로 저장할 수 있습니다.

이미지로 내보낸 페이지에서는 원본처럼 텍스트를 선택할 수 없습니다. 원본 PDF를 따로 보관하세요.

인물이나 제품을 자르지 않고 비율 변경

세로 사진을 정사각형으로 올리면 자동으로 잘리는 경우가 있습니다. 1:1이나 4:5처럼 게시 위치에 맞는 비율을 고르고, 흰색·검정·블러 중 여백을 선택하세요.

이 도구는 사진을 온전히 보이게 여백을 채웁니다. 화면을 여백 없이 가득 채우는 자르기가 필요한 경우에는 별도로 구도를 조정해야 합니다.

여러 사진에 같은 서명 넣기

사진을 함께 선택하고 텍스트나 로고를 추가합니다. 구석 서명은 우하단에서 시작해 보고, 화면 전반에 표시하려면 타일을 선택합니다.

사진별 배경 밝기가 다를 수 있습니다. 전체 저장 전에 밝고 어두운 사진을 각각 미리 보고 투명도와 크기를 조정하세요.

공유 링크에서 추적 매개변수 제거

공유 주소를 붙여넣으면 도구가 인식한 추적 항목을 제거합니다. 예를 들어 https://example.com/post?id=42&utm_source=share에서는 utm_source를 지우고 글을 가리키는 id=42를 남깁니다.

사이트별로 필요한 매개변수가 다릅니다. 정리한 주소를 새 탭에서 열어 같은 상품이나 게시글이 표시되는지 확인한 뒤 보내세요.

안내문에 링크나 Wi-Fi QR 넣기

행사 안내문이라면 완성된 링크를, 게스트 Wi-Fi 안내라면 네트워크 이름과 보안 유형을 입력합니다. 화면 공유용은 PNG, 크기를 늘려 인쇄할 때는 SVG를 선택할 수 있습니다.

인쇄 전 실제 크기에서 휴대폰 카메라로 읽어보세요. Wi-Fi QR에는 접속 정보가 포함되므로, 공유용 네트워크에만 쓰는 것이 좋습니다.
